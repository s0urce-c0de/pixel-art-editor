# Pixel art editor

This is a simple pixel art editor. I built it using closure compiler (made by google, but it is the best at its job) and HTML/JS/CSS. I documented the code using @fileoverview, etc. because typescript sucks and JSDoc doesnt need my to recompile my code every single time I want to test it.

## How to run
1. Visit https://s0urce-c0de.github.io/pixel-art-editor/
2. Click in canvas and play around.

The project isn't fully complete yet but the shortcuts are (replace ctrl with cmd on mac os):

CTRL + S: save the image<br>
CTRL + C: copy the image to the clipboard

## Issues

At the moment it is fixed 8x8 grid and red. I will update after nav buttons.
